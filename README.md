# RGC Project Atlas — Public Edition

A privacy-sanitized, static browser for 22,813 funded-project records from the
Hong Kong Research Grants Council public project search.

**Website:** <https://lba191.github.io/Hong-Kong-RGC-funding-project-atlas/>

## Features

- Search project titles, investigators, institutions, schemes, panels, and subjects
- Filter by award year, funding scheme, institution, panel, subject, and status
- Sort and choose 10, 25, 50, or 100 projects per page
- Open full project descriptions without installing software
- Responsive desktop and mobile interface

## Snapshot and privacy

- Captured: 8 October 2026 (Hong Kong time)
- Records: 22,813
- Award years: 2006/07–2026/27
- Detail-page fetch errors: 0
- Investigator email and telephone fields: excluded
- Email-like text embedded in project details: redacted

This public repository intentionally excludes the original SQLite database and
the private archival release. See [DATA_NOTICE.md](DATA_NOTICE.md).
